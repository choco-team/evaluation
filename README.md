# 티처캔 평가간소화 앱 사용방법 안내서

## 📋 앱 소개
티처캔 평가간소화 앱은 교사들의 학생 평가 업무를 효율적으로 지원하는 데스크탑 애플리케이션입니다. 학생 관리부터 문제 정보 입력, 답안지 수집, AI 평가 프롬프트 생성까지 평가의 전 과정을 디지털화하여 업무 부담을 줄여드립니다.

### 🎯 서비스 핵심 개념
**문제지 업로드** → **LLM 프롬프트 작성용**  
앱에 업로드하는 문제지는 AI에게 평가 기준을 알려주기 위한 자료로 활용됩니다.

**학생용 시험 진행** → **인쇄된 시험지 + 태블릿 답안 작성**  
- 학생들에게는 **인쇄된 시험지**를 나눠줍니다 (문제 확인용)
- 학생들은 **태블릿이나 모바일로 답안만 작성**합니다 (QR코드 접속)

**AI 평가 자동화** → **문항 + 학생답안 → LLM 평가**  
수집된 학생 답안을 문제 정보와 함께 LLM에 전달하여 객관적이고 일관된 평가를 자동으로 수행합니다.

## 🚀 시작하기

**앱 실행**
1. 티처캔 실행파일을 더블클릭하여 앱을 실행합니다
2. 앱이 시작되면 **준비 단계** 화면이 표시됩니다

## 📖 주요 기능별 사용방법

### 🏠 메인 화면 (준비 단계)
앱 실행 시 나타나는 기본 화면으로, 다음 두 개의 주요 섹션으로 구성됩니다:
- **교과 관리**: 평가할 과목과 문제 정보를 관리
- **학생 명단 입력**: 평가 대상 학생들의 정보를 등록
- **평가 기준 설정** 버튼: AI 평가에 사용할 프롬프트 템플릿 편집

---

## 1️⃣ 교과 관리

### 📚 과목 등록 및 관리
1. **새 과목 추가**
   - '교과 추가' 버튼을 클릭합니다
   - 과목명을 입력하고 엔터를 누르거나 저장 버튼을 클릭합니다
   - 추가된 과목이 카드 형태로 표시됩니다

2. **과목 수정/삭제**
   - 과목 카드에서 편집 버튼(연필 아이콘)을 클릭하여 이름을 수정할 수 있습니다
   - 삭제 버튼(X 아이콘)을 클릭하여 과목을 삭제할 수 있습니다

3. **과목 선택**
   - 과목 카드를 클릭하면 해당 과목이 선택됩니다 (파란색 테두리로 표시)
   - 선택된 과목의 문제 정보가 하단에 표시됩니다

### ❓ 문제 정보 입력 및 관리

**📝 중요 안내**: 이 기능은 문제를 새로 출제해주는 것이 아니라, 선생님께서 이미 출제하신 문제들을 체계적으로 정리하고 관리할 수 있도록 도와드리는 기능입니다.

1. **문제 정보 입력**
   - 과목을 선택한 후 하단의 문제 관리 섹션에서 문제 정보를 입력합니다
   - 입력 가능한 정보:
     - 문제 제목
     - 문제 내용 및 출제 의도
     - 문제 유형
     - 배점
     - 난이도
     - 예상 소요시간 등

2. **문제 목록 관리**
   - 입력된 문제들이 테이블 형태로 표시됩니다
   - 페이지네이션을 통해 많은 문제를 효율적으로 관리할 수 있습니다
   - 개별 문제를 클릭하여 상세 정보를 확인하고 편집할 수 있습니다

3. **평가 프롬프트 생성**
   - 과목 카드의 '평가' 버튼을 클릭하면 해당 과목의 문제 정보를 바탕으로 AI 평가용 프롬프트가 자동 생성됩니다

---

## 2️⃣ 학생 명단 입력

### 👥 학생 정보 등록 방법

#### **📁 엑셀 파일로 일괄 등록 (권장)**
1. '엑셀 업로드' 버튼을 클릭합니다
2. 학생 정보가 포함된 엑셀 파일을 선택합니다
   - **지원 형식**: .xlsx, .xls
   - **필수 열 이름**: 번호, 이름
   - **학생번호 중복 주의**: 한 컴퓨터에서 학생번호는 중복되면 안 되므로, 여러 학급을 평가하는 경우 반 번호 정보를 모두 숫자화해서 입력
     - 예) 6-1반 5번 → 60105번 또는 6105번 등
3. '업로드' 버튼을 클릭하여 학생 정보를 등록합니다

#### **✏️ 개별 학생 정보 입력**
1. 학생 정보 입력 폼에서 번호와 이름을 직접 입력합니다
2. 엔터를 누르거나 다른 필드로 이동하면 자동 저장됩니다
3. '학생 추가' 버튼으로 새로운 학생 입력 폼을 추가할 수 있습니다

#### **🗂️ 학생 목록 관리**
- 등록된 학생 목록이 실시간으로 표시됩니다
- 개별 학생 정보 편집 및 삭제가 가능합니다
- '저장' 버튼으로 변경사항을 저장할 수 있습니다

---

## 3️⃣ QR 코드 생성 및 시험 세션 관리

### 📱 시험 세션 QR 코드
1. **QR 코드 생성**
   - 메인 화면에서 'QR 코드' 메뉴로 이동합니다
   - 시험 정보를 입력합니다 (시험명, 과목, 시험 시간 등)
   - QR 코드가 자동으로 생성되어 화면에 표시됩니다

2. **QR 코드 공유**
   - 'URL 복사' 버튼을 클릭하여 링크를 복사할 수 있습니다
   - 생성된 QR 코드를 학생들에게 공유합니다

3. **실시간 모니터링**
   - **✅ 제출 완료 학생**: 답안을 제출한 학생들의 목록이 실시간으로 표시됩니다
   - **⏳ 제출 미완료 학생**: 아직 제출하지 않은 학생들의 목록이 표시됩니다
   - SSE(Server-Sent Events) 통신을 통해 실시간으로 상태가 업데이트됩니다

4. **주의사항**
   - ⚠️ **중요**: QR 코드 페이지를 닫으면 연결이 끊겨 학생들이 시험 결과를 제출할 수 없습니다
   - 시험이 완전히 종료된 후에만 '돌아가기' 버튼을 클릭하여 메인 화면으로 돌아가세요

---

## 4️⃣ 답안지 업로드 및 관리

### 📝 답안평가 생성
1. **답안 작성 페이지**
   - 'WritingPage' 메뉴를 통해 답안평가 생성 페이지로 이동합니다
   - 과목 선택 및 문제 정보를 확인합니다
   - 답안 내용을 입력하거나 편집합니다

### 📋 직접평가 기능

#### **직접평가 생성**
1. **평가 항목 생성**
   - 'DirectEvaluationCreator' 페이지에서 새로운 직접평가 항목을 생성합니다
   - 평가 제목, 설명, 과목 등을 설정합니다

2. **평가 입력**
   - 'DirectEvaluationPage'에서 학생별 직접평가를 입력합니다
   - **주요 기능**:
     - 실기 수행 과정, 발표 내용, 참여도 등을 간단히 메모
     - 점수는 선택사항이며, 빠른 입력 버튼 활용 가능
     - 평가 진행률 실시간 표시 (완료/전체)
     - 언제든 수정 가능

3. **평가 현황 확인**
   - 상단에 평가 완료율이 표시됩니다 (예: 15/30)
   - 완료된 평가와 미완료 평가를 한눈에 확인할 수 있습니다

### 🗁 파일 처리 방식

#### **자동 변환 지원**
- **HWP 파일**: 한글 문서는 자동으로 텍스트로 변환됩니다

#### **수동 입력 방식**
- **DOC, DOCX, PDF 등**: 
  1. 원본 파일을 해당 프로그램에서 엽니다
  2. 답안 내용을 복사(Ctrl+C)합니다
  3. 티처캔 앱의 답안 입력 영역에 붙여넣기(Ctrl+V)합니다

#### **이미지가 포함된 문제 처리**
- 이미지 파일은 직접 업로드할 수 없습니다
- 이미지에 대한 간단한 설명을 텍스트로 작성해주세요:
  - 예: "[그래프] x축은 시간, y축은 온도를 나타내며..."
  - 예: "[도표] 2023년 지역별 인구 현황표"
  - 예: "[그림] 삼각형 ABC에서 각 A는 90도..."

## 5️⃣ AI 평가 기준 설정

### 🤖 프롬프트 템플릿 편집
1. **평가 기준 설정 접근**
   - 메인 화면 우상단의 '평가 기준 설정' 버튼을 클릭합니다
   - 또는 메뉴에서 'promptTemplate' 페이지로 이동합니다

2. **템플릿 편집**
   - 대형 텍스트 편집기에서 평가 기준안을 수정할 수 있습니다
   - 학생 평가문 생성에 사용될 기준을 자유롭게 편집 가능합니다

3. **템플릿 관리**
   - **저장**: 변경사항을 저장합니다
   - **초기화**: 기본 템플릿으로 되돌립니다
   - **폴더 열기**: 템플릿 파일이 저장된 폴더를 엽니다
   - **취소**: 변경사항을 취소하고 이전 상태로 돌아갑니다

4. **수정 상태 표시**
   - 템플릿이 수정되면 화면에 변경사항이 있음을 알려줍니다
   - 저장하지 않고 페이지를 벗어날 때 경고 메시지가 표시됩니다

---

## 6️⃣ AI 평가 프롬프트 생성 및 활용

### 🎯 평가 프롬프트 자동 생성
1. **프롬프트 생성**
   - 교과 관리에서 평가하고자 하는 과목의 '평가' 버튼을 클릭합니다
   - 앱이 해당 과목의 문제 정보와 답안 내용을 바탕으로 평가 프롬프트를 자동 생성합니다
   - 생성된 프롬프트가 화면에 표시됩니다

2. **AI를 활용한 평가 진행**
   - 생성된 평가 프롬프트를 복사(Ctrl+C)합니다
   - ChatGPT, Claude 등 원하시는 AI 서비스에 접속합니다
   - 복사한 프롬프트를 붙여넣기(Ctrl+V)하여 AI에게 평가를 요청합니다
   - AI가 제공하는 평가 결과를 확인하고 활용합니다

### 💡 평가 프롬프트 특징
- 과목별 특성과 문제 유형을 반영한 맞춤형 프롬프트가 생성됩니다
- 객관적이고 일관된 평가를 위한 구체적인 평가 기준이 포함됩니다
- 학생 답안의 내용과 출제 의도를 종합적으로 고려한 프롬프트입니다
- 설정한 평가 기준 템플릿이 자동으로 적용됩니다

## 🔧 주요 기능 특징

### ⚡ 실시간 동기화
- Server-Sent Events(SSE)를 통한 실시간 데이터 업데이트
- 여러 사용자가 동시에 작업할 때도 최신 정보 유지
- QR 코드를 통한 학생 제출 상태 실시간 모니터링

### 📁 파일 처리 지원
- **자동 변환**: HWP 파일 (한글 문서)
- **복사-붙여넣기**: Microsoft Office 문서 (DOC, DOCX), PDF 파일 등
- **이미지 파일**: 직접 처리 불가 → 이미지 내용을 텍스트 설명으로 대체

### 💾 데이터 관리
- 모든 데이터는 로컬에 안전하게 저장됩니다
- 실시간 자동 저장 기능으로 데이터 손실 방지
- 정기적인 백업을 통해 데이터 보안 강화

## 💡 사용 팁

### 🚀 효율적인 워크플로우
1. **사전 준비**: 학기 초에 학생 정보와 과목을 미리 등록해두세요
2. **문제 정보 관리**: 출제하신 문제들의 정보를 체계적으로 입력하여 문제 데이터베이스를 구축하세요
3. **일괄 처리**: 엑셀 파일을 활용하여 대량의 학생 데이터를 효율적으로 처리하세요
4. **복사-붙여넣기 활용**: HWP가 아닌 파일들은 내용을 복사해서 직접 붙여넣기하면 빠르게 처리할 수 있습니다
5. **이미지 설명 준비**: 그래프, 도표, 그림이 포함된 문제는 미리 간단한 설명을 준비해두세요
6. **AI 평가 활용**: 과목별 '평가' 버튼으로 생성된 프롬프트를 AI에 입력하여 객관적이고 일관된 평가를 받으세요

### ⚠️ 주의사항
- 중요한 데이터는 정기적으로 백업하시기 바랍니다
- QR 코드 페이지는 시험이 완전히 종료될 때까지 닫지 마세요
- 네트워크 연결이 불안정할 때는 작업을 잠시 중단하고 안정화 후 진행하세요
- 대용량 파일 업로드 시에는 시간이 다소 소요될 수 있습니다
- 이미지가 포함된 문제는 반드시 이미지에 대한 텍스트 설명을 포함해주세요

## 🆘 문제 해결

### 일반적인 문제
**❌ 앱이 실행되지 않을 때**
- 앱을 완전히 종료 후 다시 실행해보세요
- 컴퓨터를 재시작한 후 다시 시도해보세요

**📁 파일 처리가 되지 않을 때**
- HWP 파일: 파일이 손상되지 않았는지 확인하세요
- 기타 텍스트 파일: 복사-붙여넣기 방식을 이용해보세요
- 이미지가 포함된 경우: 이미지 내용을 텍스트로 설명해서 입력하세요
- 파일이 다른 프로그램에서 사용 중이 아닌지 확인하세요

**💾 데이터가 저장되지 않을 때**
- 충분한 저장 공간이 있는지 확인하세요
- 앱에 적절한 권한이 부여되었는지 확인하세요

**🤖 평가 프롬프트가 생성되지 않을 때**
- 해당 과목에 문제 정보가 올바르게 입력되었는지 확인하세요
- 답안지가 정상적으로 업로드되었는지 확인하세요
- 과목과 답안지가 올바르게 연결되었는지 확인하세요
